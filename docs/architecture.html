The customer approves publication

Previews use private product storage. Launch & Own creates resources in the customer's GitHub and Cloudflare accounts after approval.

Live means the exact approved revision

A launch is marked live only when Cloudflare serves the GitHub commit SHA and HTML hash that were approved.

Automation never invents “live”

The durable job runner, cron resume, toolkit history, and provider inventory keep pending / unverified / reconnect states honest. Inventory discovery does not mint public live links.

Updates never touch live directly

Approved edits arrive as a pull request. Status is Approve → Merge in GitHub → Checking → Live. Closed PRs retire the Merge CTA.
